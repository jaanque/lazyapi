This project is a API Test project like postman but simple, fast and reliable.

This project only supports GET requests.
We are working on adding more features.

Just a reminder, this is a Open Source Project.
You can contribute to this project by forking the repository, making changes and then creating a pull request.
We are glad to have you here. <3
